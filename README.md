# Calculadora en Java

Programa de consola que realiza las cuatro operaciones básicas (suma, resta, multiplicación y división). Fue creado como práctica para aprender a usar **Git** y **GitHub**.

## Autor
- Daniel Morgado Marquez
- Universidad Politécnica de Tulancingo

- Materia: Comunicación y Habilidades Digitales

## Requisitos
- Java JDK 8 o superior

## Cómo ejecutarlo
```bash
javac Calculadora.java
java Calculadora
```

## Ejemplo de uso
```
===== CALCULADORA =====
1. Sumar
2. Restar
3. Multiplicar
4. Dividir
5. Salir
Elige una opcion: 1
Primer numero: 5
Segundo numero: 3
Resultado: 8.0
```
